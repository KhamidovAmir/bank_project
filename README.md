# Bank Project

Mini Banking System — учебный backend-проект мини-банковской системы.

Проект изначально разрабатывается как modular monolith, но с учетом возможного будущего перехода к микросервисной архитектуре.

Система предназначена для управления пользователями, банковскими счетами, денежными операциями, переводами и историей операций.

## Цель проекта

Проект выполняется в рамках изучения backend-разработки и практики работы с:

- Spring Boot
- Spring Security
- JWT
- PostgreSQL
- JPA/Hibernate
- транзакциями
- optimistic locking
- Docker
- документацией
- тестированием
- архитектурным проектированием

Список будет продолжаться в ходе расширения проекта.
